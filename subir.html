El orden de esta lista es el orden en la tienda. Tocá Editar para cambiar fotos, videos, datos o marcarla como vendida.

Categorías

Cada categoría es un botón en la tienda, en este mismo orden (solo se muestran las que tienen gorras). Los cambios se guardan en GitHub apenas los hacés y se ven en todos tus dispositivos.

Videos de la tienda

Aparecen en la sección "Videos" de la página. Para el video de una gorra en particular, usá "Editar" en el Catálogo (o "Agregar video" al subirla).

Agregar video

Máximo 40 MB (unos 20 a 30 segundos). Videos más largos: subilos a YouTube o Instagram y pegá el link. En iPhone conviene: Configuración → Cámara → Formatos → Más compatible, así se ven en todos los celulares.

⚙️ Configuración (una sola vez por dispositivo)

Se guarda solo en este navegador. Para generarlo: GitHub → foto de perfil → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token → marcá el permiso repo → Generate. Copiá el código que empieza con "ghp_" y pegalo acá.
